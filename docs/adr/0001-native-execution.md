# 0001 · Mandatory native execution

**Accepted for M0 and M1.** Use Python 3.12 for content, validation, reporting and command dispatch. Compile Cython 3 and C++17 with PEP 517. A missing or incompatible extension is an installation error. Keep native compilation flags and binary identity in benchmark output.

Class search repeatedly expands small integer states. A single request crosses the Python boundary once for the search, and only returned finalists become Python class documents. Keeping node expansion, conflict checks, bounds and top-K retention together makes the serial kernel measurable. The independent reference is allowed to be slow because its exhaustive domain is deliberately small.

Qualify serial work counts and result identities before adding threads. Parallel search will require an explicit merge/tie policy and its own scaling evidence.
